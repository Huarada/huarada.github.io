## projeto-professorvgc | ProfessorVGC — Coach de IA para Pokémon VGC
Busca: projeto professorvgc professor vgc pokemon coach engine python node ipc adk langchain grounding evidências pydantic benchmark fisher resultados métricas acurácia alucinações open source project accuracy hallucinations
ProfessorVGC (2026), projeto open source de coaching de IA para Pokémon VGC.
Engine Python com Clean Architecture, cálculo determinístico em Node.js via IPC e dois estágios de LLM com Google ADK e LangChain. Os estágios são alimentados apenas por evidências tipadas com Pydantic.
Benchmark com 40 partidas reais: a acurácia das afirmações do LLM passou de 52% sem grounding para 61% com grounding; p = 0,013 no teste exato de Fisher. As afirmações sobre jogadas inexistentes caíram de 87 para 11. Esses resultados se referem a esse benchmark, não a uma garantia geral de ausência de alucinações.
Repositório: https://github.com/Huarada/professor-VGC
